Before your first print

A few useful answers.

Have a particular setup in mind?
Read the setup guide

Will it work with my old USB printer?

It may, if the printer works locally with its installed driver on a supported server. ShaPrint renders print jobs through that driver. Built-in Wi-Fi is not required, but compatibility with every printer model is not guaranteed. Test your printer and the settings you need before rolling it out to your team.

Does the server computer have to stay on?

Yes. The server needs to be on, connected, and running ShaPrint with sharing enabled. A sleeping or switched-off server cannot handle print jobs.

Does this use Windows printer sharing?

ShaPrint uses its own IPPS print path rather than Windows SMB printer sharing. You still need a working local printer driver on the server. ShaPrint cannot resolve every driver, hardware, or network problem.

Can clients print across VLANs?

Yes, when the network allows clients to reach the server. Automatic discovery across VLANs depends on multicast routing or mDNS reflection. If discovery is blocked, enter the server address manually. ShaPrint does not bypass network isolation or firewall policy.

Do print jobs go through a cloud service?

The print path runs between your client and server over your network using IPPS, without a third-party cloud printing service. Downloads and app updates use Internet services.

How do I get help?

Start with the troubleshooting checklist. If the problem remains, check or open a GitHub issue. Share your operating system, printer model, and error code. Do not include your Network Channel, documents, or other sensitive information.
