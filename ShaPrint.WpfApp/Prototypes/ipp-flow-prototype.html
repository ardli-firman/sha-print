Scenario: A Windows client discovers the ShaPrint server, queries printer capabilities, and sends a print job. This is the basic happy path that must work flawlessly.
1
Query printer capabilities (Get-Printer-Attributes)
2
Send a print job (Print-Job with PWG Raster)
3
Check job status (Get-Job-Attributes)
4
Verify job completed successfully
Scenario: A client sends a multi-document print job using Create-Job + Send-Document pattern. This tests the job assembly flow.
1
Create an empty job (Create-Job)
2
Send first document (Send-Document)
3
Send last document (Send-Document with last-document=true)
4
Verify job queued for printing
Scenario: The printer encounters an error during printing. Test how the system handles failures and recovery.
1
Send a print job
2
Simulate printer error (paper jam)
3
Check job status shows error
4
Clear error and retry
Scenario: Multiple clients send print jobs simultaneously. Test job queuing and concurrency handling.

Send 3 print jobs rapidly
2
Check all jobs are queued
3

4
Verify all jobs completed
